# Roadmap

## Phase 1: Local Storage & Profiles
- Set up local database (e.g. Expo SQLite).
- Implement local user profile creation and switching.

## Phase 2: Wardrobe Digitization
- Integrate device camera to capture clothing photos.
- Save images locally to the device file system.
- Build custom category management (create, edit, delete).
- Create the main wardrobe gallery view.

## Phase 3: Visual Mix & Match
- Build an interactive UI to select and combine items (top, bottom, shoes, etc.) into an outfit.

## Phase 4: Local AI Recommendations
- Implement local recommendation logic to automatically suggest outfits.
- Display recommendations in a dedicated feed.

## Phase 5: Polish and Finalization
- Finalize styling and animations.
- End-to-end testing of the offline experience.
