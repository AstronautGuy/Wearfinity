# Architecture

## Core Architecture
- **Framework**: Expo Router based app architecture, relying on file-based routing.
- **Data Flow**: To be determined, currently appears to be standard React state management.
- **Styling Strategy**: Native CSS support in Expo using `global.css`.

## Directories
- `src/app`: File-based routes.
- `src/components`: Reusable UI components.
- `src/hooks`: Custom React hooks.
- `src/constants`: Application constants.
