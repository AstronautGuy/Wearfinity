# Testing

## Current State
- No explicit testing framework (like Jest, React Native Testing Library, or Detox) is currently set up in the project dependencies.
- Typechecking (`npx tsc --noEmit`) and linting (`npx expo lint`) are available and should be run before declaring tasks done.

## Future Recommendations
- Set up unit testing using Jest and React Native Testing Library.
- Set up E2E testing using Detox or Maestro.
